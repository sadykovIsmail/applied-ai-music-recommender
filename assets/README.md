# Assets

This folder stores project visuals used in docs and presentation.

## Current files

- `system-architecture.mmd`: Mermaid source for the system architecture diagram.

## Export step for grading

1. Open Mermaid Live Editor.
2. Paste content from `system-architecture.mmd`.
3. Export as PNG.
4. Save as `assets/system-architecture.png`.

This keeps the repo aligned with CodePath's requirement to include architecture images in a dedicated assets folder.
